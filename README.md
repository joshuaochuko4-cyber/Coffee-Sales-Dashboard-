# ☕ Coffee Sales Dashboard

An interactive Power BI dashboard analyzing 3,636 coffee shop transactions to uncover sales trends, product performance, and customer buying patterns.

## 📊 Overview

This project takes raw, transaction-level coffee shop sales data and transforms it into a clean, interactive dashboard that helps a business understand what's driving sales and where to focus next.

## 🎯 Objective

- Clean and structure raw transactional data for analysis
- Identify sales trends across time (daily, monthly, seasonal)
- Understand product performance and customer preferences
- Present findings in a way a business owner can act on

## 🗂️ Dataset

The raw dataset contains 3,636 individual transactions with the following fields:

| Column | Description |
|---|---|
| date | Date of transaction |
| datetime | Full timestamp of transaction |
| hour_of_day | Hour the transaction occurred |
| cash_type | Payment method (cash/card) |
| card | Anonymized card ID |
| money | Transaction amount |
| coffee_name | Product purchased |
| Time_of_Day | Morning / Afternoon / Night |
| Weekday | Day of the week |
| Month_name | Month of transaction |

## 🔑 Key Insights

- **Total Sales:** 115.43K
- **Total Transactions:** 3,636
- **Average Price per Transaction:** 31.75
- Sales are fairly evenly distributed across Morning (32.4%), Afternoon (33.8%), and Night (33.8%)
- **Latte, Americano, and Cappuccino** are the top-selling products
- Sales volume shows clear seasonal peaks earlier in the year and again in the fall

## 🛠️ Tools Used

- **Power BI** – dashboard design, DAX measures, data visualization
- **Excel** – initial data review and cleaning
